# NimDare

NimDare is a social accountability and skill-challenge platform built around NIM.

Users can create solo, friend, and community challenges, commit NIM toward challenges, complete them, submit proof where required, and receive the appropriate outcome or reward.

## Project Structure

```text
docs/       → Product and technical documentation
frontend/   → NimDare user interface
backend/    → NimDare API and server
```
